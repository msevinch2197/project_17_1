1️⃣ Roʻyxatni Saralash
Vazifa

Foydalanuvchidan bir nechta son kiritishni so‘rash va ularni o‘sish tartibida saralash.
sort() funksiyasidan foydalanish taqiqlanadi.

Yechim

Masalada Bubble Sort algoritmidan foydalanilgan.

Algoritm ishlash tartibi

Foydalanuvchi sonlar sonini kiritadi.

Sonlar ro‘yxatga saqlanadi.

Ikki sikl yordamida elementlar taqqoslanadi.

Katta element kichik element bilan o‘rin almashadi.

Natijada ro‘yxat o‘sish tartibida saralanadi.
